## Use the new tools

Open Toolkits → Language labs, or describe your task in the toolkit search. Choose Try sample or paste/add a file, then Analyze text. Review the method notes before interpreting scores. CSV exports the selected table; JSON contains all tables and metrics. Tables display the first 500 rows but exports include all result rows.

Syntax has two modes: English plain text produces estimated sentence/tag profiles; annotated CoNLL-U reads supplied basic dependency and morphological annotations. It does not invent dependency parses from plain text.

## Research integrity

Lexical Metrics uses documented Unicode token counts and explicit formulas. Morphology and plain-text syntax use compromise 14.14.4 predictions, which can be wrong for ambiguous or specialist language. Sentiment uses VADER-JS 1.1.3 with sentence evidence; it is not a domain-validated classifier or psychological diagnosis.

Register Profile is basic register exploration and multidimensional-analysis preparation. It does not implement MAT's 67 features, six Biber dimensions or reference-corpus z-scores. Forensic comparisons are descriptive and cannot establish authorship, plagiarism, deception or legal conclusions. Never report these exploratory tools as 100% scientifically accurate.

Full methods, pinned versions and licenses are available at toolkit/linguistics/methods.html. Existing paid MAT preparation is preserved; actual MAT tagging/analysis is performed separately. MAT itself is not installed in this development environment, so end-to-end MAT compatibility is unverified.

## Capacity and conversion

Lexical/Register: 2 million characters; English model desks: 200,000; annotated CoNLL-U: 1 million; sentiment: 12,000; forensic comparison: 500,000 per text. These focused analysis budgets do not reduce the existing large-corpus tools' capacities. No input is silently truncated. Workers can be stopped and have a 90-second time budget.

PDF output reflows text and paragraphs into A4 pages using a locally embedded Liberation Sans font. Original images, tables, columns and pagination are not reconstructed. NFC/line endings are normalized, tabs become four spaces, and long unbroken strings may wrap. Unsupported glyphs stop export with a code-point message instead of dropping content. PDF export supports up to 2 million characters and 2,000 pages per document, subject to device resources.
