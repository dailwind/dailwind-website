02 / OUTPUT SETTINGS

Your page images.

All selected pages are processed; ZIPs rotate automatically by your page count or output-size limit. Long books do not stop at 50 pages. Resolution is reduced if required by this device’s safe canvas size.

The PDF uses the order shown in the file list. Move images up/down before creating it. Original-data mode preserves supported JPEG/PNG files when no resize is needed; WebP is converted. Compress mode uses your quality and size settings. Output is image-only, without OCR text.

JPEG uses a white background. PNG preserves rendered pixels and may be much larger. Compression size is not guaranteed; already-small files may grow.

Converting a page to an image does not recognize its text. For searchable transcription, use Arc English OCR. For splitting or compressing an existing PDF, use Arc PDF Tools.

Animated images are not supported; use still PNG, JPEG or WebP. Image exports represent decoded visible pixels, not original EXIF metadata or an archival master. Color and orientation can depend on browser decoding. Check a sample before a long run.
