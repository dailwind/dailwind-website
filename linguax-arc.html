LinguaX Arc

A corpus analysis toolkit that fits in your pocket. Load a corpus, run a concordance, calculate collocates and keyness — all on the phone, with the connection switched off.

and the results were saved to the corpus without any upload taking place
each file added to the working corpus is tokenised on the device itself
a ten-million-word reference corpus can be searched in a few seconds
Get it on Google Play View source on GitHub

Tools included

  • KWIC concordanceKeyword in context, with adjustable window and sorting
  • Concordance plotWhere a term falls across the corpus
  • CollocatesConfigurable left and right span
  • ClustersRecurrent multi-word units around a node
  • N-gramsContiguous sequences, ranked by frequency
  • Word listFull frequency list with type and token counts
  • KeynessKeywords against a reference corpus
  • POS taggingPart-of-speech annotation and lemmatisation
  • SentimentDocument and segment level scoring
  • Word cloudFrequency-weighted visualisation
  • Readability and TTRReadability indices and lexical diversity
  • Corpus cleanerNormalisation, noise removal, stopwords
  • File mergerCombine files into one corpus unit
  • WorkspaceSaved sessions and analysis history

Input and output

Reads plain text, PDF, and DOCX. Results can be saved and shared from inside the app. Requires Android 7.0 or higher.
