Technical preflight notes.

The examined MAT counter divides total word length by its counted-token baseline at count_only.pl line 100. A zero baseline can trigger that error. This preflight checks that condition, but the exact cause in an individual file and every downstream MAT calculation cannot be guaranteed.

01 · Plain text goes to the tagger.

Use MAT Tag or Tag and Analyze. A cleaned text file is not tagged output. Changing its filename does not add annotations.

02 · Final MAT output goes to counting.

Use the count-input/ folder only after tagged preflight. Empty, zero-baseline, intermediate and malformed inputs stay in review/.

Use the right output folder.
  1. ready-for-tagging/ contains prepared plain text. Tag it in MAT first.
  2. count-input/ contains only files passing tagged syntax / baseline checks. Select this folder in MAT counting.
  3. review/ contains ambiguous or blocked copies. Never mix them into counting.
  4. Keep audit files outside MAT input folders. Check your MAT installation, Java/Stanford setup and original tagging output if counting still fails.
This is an independently written Dailwind utility, not an official MAT product. It preserves numbers, case and function words. It does not invent missing words, assign POS/features, run dimension scores or verify tagger accuracy. Examined MAT counter ↗ · Official MAT documentation ↗

About preparation, privacy & research integrity
Original wording, order, case, punctuation and deliberate repetitions are preserved. Automatic changes standardize text encoding, line endings, page-break whitespace and nonbreaking spaces. Suspected page markers, scanning notes and OCR placeholders are noted in the report and kept in the text.
Work runs locally in a Web Worker. Temporary local disk storage is used where supported; otherwise a bounded memory fallback is used. Capacity depends on your browser and free storage. Clear the session after downloading to release temporary files.
Books are automatically organized into numbered text parts. The manifest maps each part to its original file. The book folders and MAT input contain identical prepared copies: analyze only one copy. No tagging or MAT analysis is performed here. Read the technical preparation guide ↗
