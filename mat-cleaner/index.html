About the division-by-zero message.

The examined MAT counter divides total word length by its counted-token baseline at count_only.pl line 100. A zero baseline can trigger that error. This preflight checks that condition, but the exact cause in an individual file and every downstream MAT calculation cannot be guaranteed.

Use the right output folder.
  1. ready-for-tagging/ contains prepared plain text. Tag it in MAT first.
  2. count-input/ contains only files passing tagged syntax / baseline checks. Select this folder in MAT counting.
  3. review/ contains ambiguous or blocked copies. Never mix them into counting.
  4. Keep audit files outside MAT input folders. Check your MAT installation, Java/Stanford setup and original tagging output if counting still fails.
